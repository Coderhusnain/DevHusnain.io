About

I’m a Full Stack Web Developer with 3 years of experience building scalable and high-performing web applications. I specialize in MERN and MEVN stacks, along with Python frameworks such as Flask, Django, and FastAPI, and craft efficient, user-friendly interfaces using React.js, Vue.js, CSS, Bootstrap, and Tailwind. I also develop custom WordPress websites and scalable e-commerce solutions, delivering visually refined and performance-driven products for clients worldwide.

Services

Full-Stack Web Development

End-to-end web applications using MERN / MEVN stacks. Clean architecture, component-driven frontends and scalable Node/Express backends ready for production.

Frontend Engineering

Responsive, accessible UIs built with React.js or Vue.js, styled with Bootstrap / Tailwind. Focus on performance, UX polish and cross-device consistency.

Backend & API Development

Robust REST / GraphQL APIs using Node, Flask or FastAPI. Authentication, role-based access, webhooks and third-party integrations with secure, documented endpoints.

E-commerce & WordPress Solutions

Custom WooCommerce / WordPress sites, headless e-commerce, payment integration and store optimizations focused on conversions and reliability.

Automation & Web Scraping

Reliable data collection and automation using Python (BeautifulSoup, Selenium / Playwright). Scheduled jobs, data pipelines and cleanup for production use.

Databases & Deployment

Database design, indexing and migrations (MySQL, PostgreSQL, MongoDB). Docker, Nginx and deployment workflows for fast, reliable releases and backups.
